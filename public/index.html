Your password is used once to obtain a refresh token and is never stored. The bridge keeps the token current on its own from then on. Restarting is how the running process picks up a new token — under systemd or Docker it comes straight back.

This bridge requires an admin token for changes. Enter it below.

Changes are written to the config file and survive a restart. The encoder restarts, but the RTSP session survives it — connected clients keep their connection because the server rewrites RTP headers across the restart. Resolution above 1920×1080 gains nothing; Ring's source is 1080p. Substreams are configured in the file, not here.
